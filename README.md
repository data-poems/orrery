# Screenshots for the iPhone Duo tabletop PR

Image-only branch for the pull request from `claude/duo-tabletop-20261114`. Not
for merging; delete it once the PR is merged or closed.

Shots marked SIMULATED are WebKit viewports (Playwright 1.65.1, WebKit 27.2)
with the app's own fold shim fed the Duo simulator's fold regions, because the
simulator's inner screen needs a Device Hub click to unfold. The outer-screen
shot is from the iPhone Duo simulator (iOS 27.2, Xcode 27.2).
